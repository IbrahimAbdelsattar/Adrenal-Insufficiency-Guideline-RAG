  [TXT] Question → Evidence → Answer, or a Safe Refusal

  [TXT] relevance_floor 0.30 — weak matches flagged, not hidden

======== Slide 8
  [TXT] RETRIEVE EVIDENCE
  [TXT] Structured Dual Retrieval
  [TXT] Two independent retrievers run every query in parallel — each returns a fully-structured, citation-ready result, not just raw text.
  [TXT] Dense Cosine Retriever
  [TXT] retrieval/dense.py
  [TXT] Embeds the query, queries ChromaDB for nearest vectors, scores by 1 − distance. Captures semantic / paraphrased meaning.
  [TXT] BM25 Lexical Retriever
  [TXT] retrieval/bm25.py
  [TXT] In-memory clinical tokenizer scores exact term overlap — catches precise drug names, doses, and section numbers dense search can miss.
  [TXT] Reciprocal Rank Fusion  (k = 60)
  [TXT] RetrievalResult — every returned chunk carries: chunk_id · document_name · page_number · section_title · section_number · source_url · score (rank 1-indexed) · below_floor flag — stored natively, never in an external sidecar file.

======== Slide 9
  [TXT] RETRIEVE EVIDENCE
  [TXT] Hybrid Search Strategy: Vector + Keyword
  [TXT] Semantic and lexical search fail in different, complementary ways. Eva AI fuses both ranked lists with Reciprocal Rank Fusion so a chunk ranking highly on either signal surfaces near the top.
  [TXT] RRF SCORE FORMULA
  [TXT] score(d) = Σ  weight ×  1 / (k + rankᵢ(d))
  [TXT] k = 60 · summed across the dense and BM25 ranked lists · scores min-max normalised before the relevance floor is applied.
  [TXT] WHY HYBRID WINS ON THIS CORPUS
  [TXT] Catches exact drug names & dose numbers (BM25) missed by pure semantic search
  [TXT] Catches paraphrased clinical questions (dense) missed by pure keyword search
  [TXT] No reranker required for the default path — 12ms/query and higher Precision@3 than reranking on this corpus

======== Slide 10
  [TXT] RETRIEVE EVIDENCE
  [TXT] Re-Ranking System: Cross-Encoder
  [TXT] An optional cross-encoder reranker (cross-encoder/ms-marco-MiniLM-L-6-v2) re-scores the fused candidate list with full query–chunk cross-attention — sharper than similarity alone, at a latency cost.
  [TXT] Cross-Attention Scoring
  [TXT] Every (query, chunk) pair is scored jointly by the transformer, then calibrated to [0,1] with a sigmoid.
  [TXT] Fail-Safe Fallback
  [TXT] If the model fails to load or errors at inference, the system falls back to normalised step-decay scoring — it never crashes.
  [TXT] Latency Fix: -28%
  [TXT] Truncating each chunk to 1800 chars before scoring bounded batch padding width — 4437ms → 3194ms/query, same ranking output.

======== Slide 12
  [TXT] SYSTEM GUARDRAILS
  [TXT] In-Domain Hallucination Prevention
  [TXT] Three independent, fail-closed layers stand between a query and the LLM — verified by a 77-test stress suite (0 failures).
  [TXT] Layer 0 — Injection Guard
  [TXT] ~25 deterministic regex patterns block override phrases, DAN/jailbreak personas, prompt-reveal attempts, and delimiter injection — <1ms overhead.
  [TXT] Layer 1 — Scope Classifier
  [TXT] classify_scope() rejects out-of-scope clinical domains (cardiology, asthma, diabetes) at threshold 0.005 before generation is attempted.
  [TXT] Layer 2 — Floor Guard
  [TXT] should_abstain() refuses when every retrieved chunk sits below relevance_floor = 0.30 — weak evidence is shown, never silently used.
  [TXT] HARDENED GROUNDING PROMPT — 6 RULES
  [TXT] Evidence-Only (no parametric memory)
  [TXT] Mandatory Citations on every claim
  [TXT] Explicit Abstention when evidence absent
  [TXT] Clinical Precision — verbatim drug/dose
  [TXT] Scope Enforcement — standard refusal msg
  [TXT] Structured Format — bullets vs prose
  [TXT] 77 / 77 grounding, scope & citation tests passing in 2.9s  ·  23/23 known injection patterns detected  ·  11/11 benign queries never blocked
